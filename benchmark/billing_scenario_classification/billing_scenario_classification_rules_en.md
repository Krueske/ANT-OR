# Bill Scenario Classification Task - Annotation Rules Document

## I. Rules and Examples

### 1.1 Annotation Basics

Categorization should be determined based on a comprehensive assessment of the transaction content. The transaction content must clearly correspond to the definition of a specific category; otherwise, it should be classified as "Others."

### 1.2 Data Description

* **Transaction Content**: Describes the specifics of the current transaction, indicating its exact nature.
