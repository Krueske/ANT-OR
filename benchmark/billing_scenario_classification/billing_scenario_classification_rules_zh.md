# 账单场景分类任务标注规则文档

## 一、规则及案例

### 1.1 标注基础说明

根据交易内容综合判断文本对应的类目分类，交易内容必须明确指向各类目定义才可以，否则属于其他。

### 1.2 数据描述

* **交易内容**：本次交易的内容，表明这个交易的具体情况。

### 1.3 标注说明

类目名称与定义

| 一级类目名称 | 一级类目语义                                                    |
| ------ | --------------------------------------------------------- |
| 餐饮美食   | 涵盖正餐、快餐、酒水、生鲜食品、零食以及烟酒等相关消费与服务。                           |
| 服饰装扮   | 男女装、鞋包及首饰等零售消费，覆盖专卖店、电商平台及饰品品牌等消费。                        |
| 日用百货   | 涵盖日常生活所需商品的零售服务，包括百货超市、便利店、鲜花绿植及社区团购等消费。                  |
| 家居家装   | 涵盖家具、建材及装修服务，提供家纺、灯具等居家产品，优化生活空间。                         |
| 数码电器   | 涵盖大家电、小家电及3C数码产品的购买与相关消费。                                 |
| 运动户外   | 涵盖健身房、瑜伽舞蹈、体育场馆及户外运动器材等相关消费。                              |
| 美容美发   | 涵盖美容美发相关消费，包括美妆个护、护肤、面膜、美甲及理发、烫染等服务与产品。                   |
| 母婴亲子   | 涵盖婴童用品、儿童服饰、玩具及母婴相关商品与服务的消费。                              |
| 宠物     | 涵盖宠物及相关服务消费，包括宠物用品、宠物玩具、宠物医院、宠物服饰及美容等服务。                  |
| 交通出行   | 涵盖交通及出行消费，包括机票、船票、火车票、汽车票等城际交通，以及地铁、公交、高速费用等市内出行。         |
| 爱车养车   | 加油充电、维修保养及停车服务，涵盖汽修店、加油站、充电站及汽车/自行车用品销售等。                 |
| 住房物业   | 房租、物业费及中介服务，涵盖物业管理、房产租赁及中介机构服务。                           |
| 酒店旅游   | 涵盖酒店住宿及旅游相关消费，包括景区门票、酒店民宿、旅游套票、出游服务及年卡等。                  |
| 文化休闲   | 涵盖影视娱乐、演出赛事及休闲场所消费，涵盖影院、酒吧、棋牌等，服务线下场馆及线上平台的消费。            |
| 教育培训   | 涵盖教育培训相关消费，包括学费缴纳、网课购买、公立及民办教育机构和培训服务等。                   |
| 医疗健康   | 涵盖医院诊所、体检保健、医疗美容、医药器械及营养保健品等相关服务与消费。                      |
| 生活服务   | 解决生活事务性需求，租赁、物流、家政维修、同城配送、法律婚庆等专项服务等费用。                   |
| 公共服务   | 政府机构提供的行政、司法、社保、公积金等公共事务管理及非营利组织服务等费用。                    |
| 商业服务   | 金融、运输、营销及财税咨询等企业运营支持与电商交易保障服务产生的费用。                       |
| 公益捐赠   | 进行慈善捐赠的交易，例如基金会（壹基金）、公益平台（水滴筹）或寺庙（香火钱）的消费、或公益筹款（乡村小学）的消费。 |
| 互助保障   | 支付互助保障计划的交易，例如网络互助（相互宝分摊）或社区保险（邻里医疗基金）的消费。                |
| 投资理财   | 涵盖金融产品购买、投资服务及金融机构相关交易与费用支出。                              |
| 保险     | 涵盖各类保险产品及服务，包括投保、理赔、赔付及相关保障性费用。                           |
| 信用借还   | 涵盖共享租赁、借贷平台及金融租赁等相关服务与费用支出。                               |
| 充值缴费   | 涵盖水电燃气、通讯及网络充值服务，涵盖公共事业缴费、话费流量充值及电信运营商服务。                 |
| 收入     | 各类利益收入。                                                   |
| 转账红包   | 转账红包相关内容。                                                 |
| 亲友代付   | 亲友代付内容。                                                   |
| 账户存取   | 账户存取的余额内容。                                                |
| 退款     | 标题内明确涵盖退款字眼、或其他退款账单。                                      |
| 其他     | 不属于以上一级类目的内容。                                             |
