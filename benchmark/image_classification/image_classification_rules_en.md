# Product Material Classification and Tagging Guidelines

## I. Category Identification

**Principle:** Determine which **primary category** the material belongs to. If none applies, label it as **Other**. Then determine which **secondary categories** it matches. There may be more than one secondary category (for example, an image of an iPhone that also emphasizes it is a new flagship model). If none applies, label it as **Other**.

## II. Copywriting Analysis

### Analysis Dimensions

| Orientation Type | Judging Standard | Examples |
|---|---|---|
| **Value / Functional Orientation** | Marketing copy **does not include discounts/promotions** and starts from product functions, advantages, etc. | Performance description, function introduction, ingredient description, material description |
| **Benefit Orientation** | Copy **includes promotions**, activities, free SF Express shipping, exclusive high-score offers, etc. | Discount amount, promotional event, “buy one get one,” “coupon discount,” “free shipping,” “next-day delivery,” etc. |
| **Trend / Hot Topic Orientation** | Marketing copy includes popular time-sensitive elements or events, such as Labor Day travel, equestrian festival, cherry blossom festival, Mayday concert, Dragon Boat Festival, Mid-Autumn Festival, National Day, Spring Festival, etc. | Includes specific events, holidays, seasons, or trending topics |

### Decision Rules

1. **Value / Functional Orientation**: The copy only starts from the product’s functions, performance, features, ingredients, materials, etc., and does not involve any discount or promotional information.

2. **Benefit Orientation**: Includes coupons, discounts, full-reduction offers, gifts with purchase, free shipping, limited-time special price, flash sale, and similar benefit-related descriptions.

3. **Trend / Hot Topic Orientation**: The copy includes holidays (Spring Festival, Mid-Autumn Festival, Dragon Boat Festival, etc.), seasons (“spring new arrivals,” “autumn wear,” “summer”), concerts, special events, or other time-sensitive trending content.

**Note:** A single piece of copy may satisfy multiple orientation types. For example, “Dragon Boat Festival coupon” contains both a hot topic/event element (Dragon Boat Festival) and a benefit element (coupon), so **both labels should be selected**.

## III. Typical Cases

| Case Type | Key Judgment Point | Example Explanation |
|---|---|---|
| Gaming Phone | Copy contains keywords such as “esports-grade” or “gaming” | Mobile phone mainly promoting gaming performance |
| Camera Phone | Copy mentions “taking photos,” “photography,” “telephoto,” “lens,” etc. | Emphasizes photography capabilities |
| Smart Watch | Smart watches all have sports tracking functions, so both “Sports Watch” and “Smart Watch” should be selected | Such as Apple Watch, Huawei Watch, etc. |
| Hot Topic + Benefit | For example, “Dragon Boat Festival coupon” includes both an event and a benefit, so select 2 labels | Holiday promotion campaign |
| Seasonal New Arrivals | “Autumn new arrivals,” “summer limited edition,” etc. belong to trend/hot topic orientation | Seasonal product promotion |
| Functional Selling Point | “3 light colors,” “eye protection,” etc. belong to value/functional orientation | Emphasizes product functions and features |
| Promotional Offers | “Buy one get six,” “coupon discount,” etc. belong to benefit orientation | Promotional poster |
