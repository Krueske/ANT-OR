## 二、话术分析

### 分析维度

| 导向类型       | 判断标准                                           | 示例                                  |
| ---------- | ---------------------------------------------- | ----------------------------------- |
| **价值功能导向** | 营销词**不包含优惠**，从产品功能、优势等出发                       | 产品性能描述、功能介绍、成分说明、材质介绍               |
| **利益点导向**  | 话术**包含优惠**、活动、顺丰包邮、高分专享等                       | 优惠金额、优惠活动、"买一送一"、"领券立减"、"包邮"、"次日达"等 |
| **热点导向**   | 营销词中有热门时间、事件，如五一出游、马术节、樱花节、五月天演唱会、端午、中秋、国庆、春节等 | 包含具体事件、节日、季节、热点话题                   |

### 判定规则

1. **价值功能导向**：仅从产品的功能、性能、特点、成分、材质等方面出发，没有涉及任何优惠、活动信息

2. **利益点导向**：包含优惠券、折扣、满减、买赠、包邮、限时特价、秒杀等利益相关描述

3. **热点导向**：文案中包含节日（春节、中秋、端午等）、季节（春上新、秋装、夏日等）、演唱会、特殊事件、热门话题等时效性内容

**注意：** 一篇文案可能同时满足多个导向类型，如"端午优惠券"既包含热点（端午）又包含利益（优惠券），应同时选择两个标签。

## 三、典型案例

| 案例类型  | 判断要点                           | 示例说明                  |
| ----- | ------------------------------ | --------------------- |
| 游戏手机  | 文案出现"电竞级"、"游戏"等关键词             | 主打游戏性能的手机             |
| 摄影手机  | 写了"拍照"、"摄影"、"长焦"、"镜头"等跟摄影相关的   | 强调摄影功能的手机             |
| 智能手表  | 智能手表都具有运动检测功能，运动手表和智能手表两个标签都选  | 如Apple Watch、华为Watch等 |
| 热点+利益 | 如"端午优惠券"，既有事件（端午）又有利益（优惠券），选2个 | 节日促销活动                |
| 季节新品  | "秋上新"、"夏日限定"等属于热点导向            | 季节性商品推广               |
| 功能卖点  | "3种光色"、"护眼"等属于价值功能导向           | 强调产品功能特点              |
| 优惠活动  | "买一送六"、"领券立减"等属于利益点导向          | 促销活动海报                |
