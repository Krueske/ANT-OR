# 医疗实体识别任务规则

标注细则：
汇总一下所有需抽取字段，如下：

| 实体类型 | 说明 |
| --- | --- |
| 病症 | 疾病词、症状词，症状词含广义上的体征、检验检查异常等。不要加多余的程度副词。<br/>如慢性咳嗽、颈椎间盘突出、过敏性皮炎、急性喉炎、膀胱结石、高血压、心绞痛、头晕、头痛、视觉疲劳、妇科疾病、甲状腺功能减退、肺气囊等。 |
| 检验检查 | 检验检查项目或指标词。如肝功能、血常规、CT检查、空腹血糖等。 |
| 手术操作 | 手术或医疗操作词。如口腔正畸、斜视手术、隆鼻、洗牙、ICL晶体植入手术等。 |
| 器官 | 器官或部位词。如眼睛、肝脏、手指。如果器官词已经被包含在其他实体类型中，则不要抽器官词。（如“头疼”只抽病症“头疼”，不抽“头”） |
| 省份 | 如浙江、浙江省。 |
| 城市 | 如北京、北京市。 |
| 区县 | 如余杭、黄浦区、昆山市、桐庐。 |
| 医院 | 医院名称，如上海市东方医院。注意，如果医院名称中包含省份、城市、区县，在省份、城市、区县字段也要抽取。 |
| 医院类型 | 如三级医院、二级医院、综合医院、公立医院、肿瘤医院、中医院、皮肤科医院等，表示为某一类型的医院。 |
| 科室 | 如消化科、妇产科。其他实体类型下包含科室名称的，在科室里不重复抽。（如“杭州市骨科医院”抽医院“杭州市骨科医院”和城市“杭州市”，不抽“骨科”） |
| 人名 | 如周杰伦、马云。其他实体类型下包含人名的，在人名里不重复抽。（如“宁波李惠利医院”抽医院“宁波李惠利医院”和城市“宁波”，不抽“李惠利”） |
| 医生性别 | 类似男医生、女医生类的表述。 |
| 医生姓氏 | 类似张医生、王大夫、张主任的表述。如果已有人名，不重复抽姓氏。（如“钟南山医生”抽人名“钟南山”，不抽姓氏“钟”/“钟医师”） |
| 药品成分名 | 化学成分，如布洛芬、青霉素、阿莫西林。 |
| 药品通用名 | 一般是化学成分+剂型组合，如布洛芬缓释胶囊、阿莫西林克拉维酸钾片。<u>包含比较清晰无歧义的通用名缩写，如感冒灵、板蓝根、连花清瘟</u>。 |
| 药品商品名 | 一般是某个药的商品的名称，如芬必得、立普妥、阿莫灵。 |
| 药品品牌名 | 这个通常指的是厂家名，如中美史克、拜耳。 |
| 中药材 | 如当归、党参、土茯苓、麦冬。 |
| 药品其他 | 是药品，但归不到上述类型。如感冒药、抗生素、非甾体抗炎药、降压药。 |
| 保健食品 | 如钙锌凝胶糖果、B族维生素片、脑白金、汤臣倍健。（保健食品可能不便于区分更细致的通用名、成分名、商品名等，所以合起来了） |
| 特医食品 | 如特殊医学用途全营养配方粉。（特医食品可能不便于区分更细致的通用名、成分名、商品名等，所以合起来了） |
| 医疗器械 | 如体温计、血压计、欧姆龙。（医疗器械可能不便于区分更细致的通用名、成分名、商品名等，所以合起来了） |
| 疫苗 | 疫苗词。如流感疫苗、九价疫苗、科兴疫苗等。（疫苗可能不便于区分更细致的通用名、成分名、商品名等，所以合起来了） |
