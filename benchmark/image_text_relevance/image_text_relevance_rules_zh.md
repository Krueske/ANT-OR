## 图文相关性评估标准

## 一、评分等级定义

| 评分     | 等级  | 核心定义                                  |
| ------ | --- | ------------------------------------- |
| **2分** | 强相关 | 图片直接、完整地回答了搜索词的问题或意图，观看图片后能获得明确的答案或信息 |
| **1分** | 弱相关 | 图片与搜索词存在一定关联，能提供部分信息或氛围，但无法完全回答搜索意图   |
| **0分** | 不相关 | 图片与搜索词无明显关联，无法提供任何有价值的信息              |

## 二、分档标准详解

### 2分（强相关）判定标准

**必须同时满足以下条件：**

1. **主体匹配**：图片清晰展示了搜索词的核心主体（人物、物品、场景、概念）

2. **语义完整**：如果搜索词包含限定条件（如"红色苹果"），图片中的主体需满足这些限定

3. **意图响应**：图片能够直接回应搜索词的问题或需求

**典型场景：**

* 搜索"巴黎铁塔" → 图片展示清晰的埃菲尔铁塔

* 搜索"红色跑车" → 图片展示红色跑车，颜色与车型均匹配

* 搜索"煮鸡蛋" → 图片展示煮鸡蛋的步骤或成品

### 1分（弱相关）判定标准

**满足以下任一条件即可：**

| 弱相关类型    | 判定标准                        | 示例说明                |
| -------- | --------------------------- | ------------------- |
| **部分匹配** | 图片包含搜索词的部分元素，但未完整表达         | 搜索"海边日落"，图片只有海边没有日落 |
| **条件缺失** | 主体匹配，但搜索词中的限定条件不满足          | 搜索"红色苹果"，图片是绿色苹果    |
| **氛围匹配** | 图片难以直接对应搜索词字面意思，但能传达相关氛围或情绪 | 搜索"浪漫晚餐"，图片展示烛光但无食物 |
| **间接关联** | 图片与搜索词存在间接逻辑关联              | 搜索"减肥"，图片展示健身房器械    |


### 0分（不相关）判定标准

**满足以下任一条件即可判定为0分：**

| 不相关类型    | 判定标准                  | 示例说明             |
| -------- | --------------------- | ---------------- |
| **完全不符** | 图片内容与搜索词字面意思完全不同      | 搜索"猫"，图片是汽车      |
| **误导性**  | 图片可能让人产生错误联想或与搜索词矛盾   | 搜索"健康饮食"，图片是垃圾食品 |
| **信息缺失** | 图片过于抽象、模糊或无任何可识别元素    | 搜索"长城"，图片是一片纯色   |
| **无法理解** | 正常用户无法建立图片与搜索词之间的逻辑联系 | 搜索"2+2"，图片是一朵花   |

## 三、意图不明搜索词（直接判定为不相关）

### 什么属于"意图不明"

意图不明是指搜索词本身缺乏明确的指向性，无法直接判断用户想要找什么图片。这一类直接判定为不相关，常见类型包括：

| 类型       | 特征           | 示例              |
| -------- | ------------ | --------------- |
| **模糊表达** | 口语化、不完整的句子   | "来看看咯"、"随便看看"   |
| **问题型**  | 疑问句形式，需要信息回答 | "会员怎么取消"、"我挂的号" |
| **权限确认** | 询问是否可以/能否    | "我可以申请吗？"       |
| **主观描述** | 缺乏客观实体指向     | "这个东西好用吗"       |
