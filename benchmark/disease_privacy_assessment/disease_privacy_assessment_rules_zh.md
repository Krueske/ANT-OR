

# 疾病名称隐私评估任务标注规则

| **题目** | **要求** | **备注/案例** |
|:---:|---|---|
| **隐私合规** | 不为隐私疾病信息，如性病（hiv、尖锐湿疣等性传播类疾病，乙肝结核不包括在内）/隐私类疾病（阳痿、早泄等）/精神类疾病 | **有隐私问题：** 肛周疣 |

下面的隐私相关细则中，高度私密等级及以上的疾病名称或query需判定为隐私合规问题。

## 一、隐私相关细则

### 隐私内容定义

#### 1、疾病私密等级划分

| 等级 | 名称 | 判定依据 |
|:---|:---|:---|
| L4 | 超高私密 | • 明确的存在隐私问题的疾病名称或低俗恶趣味的疾病查询 |
| L3 | 高度私密 | • 疾病名称将易引发歧视、羞辱、社会污名• 违反公序良俗或平台价值观 |
| L2 | 中度私密 | • 涉及私密身体/行为，但无明确疾病或歧视风险• 属于个人生活隐私，公开会引发尴尬 |
| L1 | 一般私密 | • 日常可讨论但需场合的内容• 无健康问题公开风险 |

#### 2、隐私分类

在医疗健康场景中存在大量私密话题和信息，需要针对医疗场景特殊定制隐私意图。隐私意图设计包含三个维度"健康隐私""身体隐私""行为隐私"。

| 隐私定义 | 定义 | 案例 | 隐私等级 |
|:---|:---|:---|:---|
| 健康隐私 | 可能引发社会歧视、污名化、就业/保险受限的疾病或健康状态 | （1）性传播感染（STIs）（2）法定传染病（乙类及以上）排除：普通感冒、流感、手足口病（轻症）不在此列（3）重大/恶性疾病（4）精神心理疾病 排除：轻度压力、失眠、情绪低落等日常表述（5）遗传/罕见病/残疾相关（6）性生殖相关疾病（7）肛门疾病 | 高度私密（L3） |
| | | （1）普通感冒、流感、手足口病（轻症） | 一般私密（L1） |
| | | （2）轻度压力、失眠、情绪低落等日常表述 | 中度私密（L2） |
| 身体隐私 | 直接、间接或隐喻性描述人体私密部位 | （1）男性生殖器官：包含隐喻：屌、那话儿、命根子、小弟弟、鸡鸡、老（2）女性生殖器官：包含隐喻：下面、私处、私密位置、秘密花园、女人那儿（3）第二性征/哺乳相关：包含隐喻：胸脯、双峰、玉兔、咪咪、奶奶、小馒头、小山丘（4）其他私密部位：肛门、屁股（仅当涉及排泄/性行为时）、尿道口 | 高度私密（L3） |
| | | （1）需上下文判断不属于私密区域问题：胸痛 | 一般私密（L1） |
| 行为隐私 | 讨论通常被视为私密、不宜公开的生理功能或排泄行为。 | （1）排泄物：【低俗恶趣味关键词】吃屎、喝尿治病、粪便美容（1）性行为相关：【低俗恶趣味关键词】 | 超高私密（L4） |
| | | （1）性行为相关：【合理健康关键词】性交疼痛、射精太快（2）其他私密生理现象：呕吐（可能指向怀孕）、体味（狐臭、私处异味） | 高度私密（L3） |
| | | （1）排泄物：【合理健康关键词】大便、粪便、拉稀、腹泻、黑便、血便、尿、小便、尿频、尿急、尿痛、屁、放屁、臭屁 | 中度私密（L2） |
| | | （1）月经与妇科分泌（2）其他私密生理现象：放屁、打嗝 | 中度私密（L2） |

**注意：涉及乙肝的问题先卡掉，判为隐私合规问题；**
